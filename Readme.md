# Light Following Robot Without Microcontroller

## Overview

This project demonstrates a light-following robot built without using any microcontroller.

The robot uses an LDR sensor, BC547 transistor, SPDT relay, and two DC motors. The resistance of the LDR changes with light intensity, which drives the transistor and relay to switch between motors, enabling the robot to move toward a light source.

## Components

- LDR
- BC547 Transistor
- SPDT Relay
- 10kΩ Resistor
- 1kΩ Resistor
- 1N4007 Diode
- Two DC Motors
- Breadboard
- 6V–9V Battery
- Robot Chassis

---

## Working Principle

1. Light falls on the LDR.
2. LDR resistance decreases.
3. BC547 transistor turns ON.
4. Relay energizes.
5. Motor switching occurs.
6. Robot turns toward the light source.
